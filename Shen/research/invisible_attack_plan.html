論文重現與分工規劃

Invisible Adversarial Attacks on Deep Learning-Based Face Recognition Models
Lin et al., IEEE Access 2023

1. 論文方法

1.1 Mask 生成

  1. 用 facial landmark 抽出眉、眼、鼻、嘴的區域，組成初始 mask。
  2. 對整張臉做 superpixel 分割，任何與初始 mask 有交集的 superpixel 整塊納入，形成最終 mask，讓邊緣比純 landmark mask 更自然。

1.2 攻擊

基於 FGSM / BIM / PGD，差別在每一步算出梯度後先乘上 mask，再加到影像上：

x0 = x + Crop_m(r)
x_(i+1) = Clip_{x,ε} { x_i + Crop_m( α · sign(∇x L(x_i, y)) ) }

loss = CE loss + TV loss。TV loss 讓擾動更平滑，有利於列印再拍攝的 physical attack。

1.3 評估

  • ASR：cos(F(x), F(x_adv)) < τ 的比例。
  • 各模型的 τ：FaceNet 0.409、ArcFace 0.302、IRSE50 0.241、IR152 0.167。
  • SSIM：衡量人眼不可見度。
  • ε = 20/255。
  • 白箱模型：FaceNet（CASIA-WebFace 預訓練）；黑箱轉移目標：IR152、IRSE50、ArcFace。
  • 基準方法為 FGSM / BIM / PGD，各自做有 mask / 無 mask 對照。
  • 結論：加上 mask 後 SSIM 顯著上升，ASR 只小幅下降。
  • 另外做了列印 + 掃描的 physical attack 實驗。

3. 里程碑

M0 — unmasked baseline（不用寫新 code）

先用 Yeah 現成的東西跑一輪：pgd_full 打 LFW development split → run_verification_robustness.py → evaluate_perceptual_v1.py。拿到 ASR / SSIM / LPIPS 的基準數字，之後 mask 的效果才有得比。這步同時驗證環境與權重都裝對了。

M1 — 最小可發表對照

mask 生成 + masked 攻擊註冊進 registry，用同一組 grid 再跑一次，產出「有 mask vs 無 mask」的 ASR 與 SSIM 對照表（對應論文 Table 1、Table 2）。驗收門檻：SSIM 明顯上升、ASR 只小幅下降。不成立就停下來檢討，不要往下堆。

M2 — 延伸

TV loss、ε 與 superpixel 數量掃描、補 IR152 / IRSE50 當 victim 與轉移評估。

5. 先講好的介面

新東西一律插進 Yeah 既有的介面，不要另開 pipeline。開工前要定好的四件事：

  • A 的 mask 格式（HxW 的 0/1 uint8 numpy array，與原圖同尺寸、BGR 座標系）
  • mask 怎麼進到攻擊裡：走 AttackConfig.extra["mask"]，不改 AttackConfig 的既有欄位
  • B 註冊的 attack name（例如 masked_pgd_full），以及 AttackSpec.linf_constraint_domain 要標成什麼
  • 結果一律落在 results/<family>/<run>/（由 advface/paths.py 決定），D 的評估腳本只讀這裡
