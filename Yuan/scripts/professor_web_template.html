01 / ALIGN THE OBJECTIVE

對準驗證使用的 A：A-reference

讓攻擊最佳化的照片對，和最後驗證的照片對一致。

先定義三張圖：A 是固定的參考照片，B 是同一人的另一張照片，加入擾動後得到 B_adv。最後要判斷的是「A 和 B_adv 是否仍被模型接受為同一人」。

參考 A固定，不修改
＋
原圖 B加入受限擾動 δ
→
B_adv與 A 作驗證

原本的程式使用 B 當參考，讓修改圖遠離原始 B。但 A 和 B 的特徵向量會因姿勢、光線或表情而不同，遠離 B 的方向，未必就是最有效遠離 A 的方向。

原本：self-reference

min cos(f(B), f(B_adv))讓修改圖不像原本的 B

評估時仍然比較 A–B_adv，最佳化目標與評估照片對有差異。

改成：A-reference

min cos(f(A), f(B_adv))直接降低實際驗證 pair 的相似度

A 使用自己的 landmarks 對齊，embedding 固定；梯度回傳到 B 的擾動。

怎麼判斷攻擊成功？

先確認原始 A–B 的 cosine 高於門檻，再看修改後的 A–B_adv 是否降到門檻下方。ArcFace 用來生成擾動；FaceNet 使用自己的前處理與 embedding，只評估結果，不回傳攻擊梯度。

clean cosine ≥ τ　→　adversarial cosine < τFaceNet 門檻 τ＝；這個條件成立才算攻擊造成跨界。
同一批20人，FaceNet 跨界案例從8人增加到13人：40% → 65%。
主要改動是固定參考向量由 B 換成 A；ε、迭代步數與 MI-FGSM 設定相同。

實際例子：Meryl Streep

02 / DIVERSE INPUTS

DI — Diverse Inputs
輸入多樣化

每一步讓模型看到稍微不同的輸入，嘗試減少擾動對固定縮放與位置的依賴。

A-reference 決定「要遠離誰」，DI 則改變「每一步用什麼輸入計算梯度」。本次 DI 放在 B_adv 的可微分人臉對齊之後、送進 ArcFace 之前；參考 A 的 embedding 持續固定。

對齊後 B_adv112×112，RGB 正規化
→
隨機縮小＋padding回到112×112
→
ArcFace loss對固定 f(A) 計算 cosine

本次固定的設定

以 p＝0.7 選擇變換，縮小到原尺寸的 90%–100%，再隨機放置並 padding 回112×112。

Padding 使用正規化值0，對應 RGB＝127.5；抽到原尺寸時可形成 identity 變換。

實驗與輸出

seed＝0；每組200步中實際使用 126次非 identity 變換。

變換用於求梯度。最後保存的是原尺寸 B_adv，評估使用存成 PNG 後重新讀回的圖片。

用示意框看縮放與位置的變化

112×112輸入框示意；灰色區域表示 padding
固定參考：f(A)
A 不隨 B 的變換而重新抽樣

此互動是概念示意，不是實驗照片，也不重新產生攻擊或改變下方數據。

沿用 A-reference，加入 DI 後：13/20 → 14/20，65% → 70%。
這組設定新增 Jennifer Rodriguez 成功，沒有成功轉失敗。

DI 生成的梯度會穿過縮放、padding 與對齊運算，回到原圖上的 δ；後續仍用 MI-FGSM 的 L1 正規化、momentum 和 sign 更新，並投影回相同的 ε 預算。

DI 參考：Improving Transferability of Adversarial Examples with Input Diversity（CVPR 2019）。

本次為配合 ArcFace 固定輸入尺寸的 shrink＋pad 變體，參數固定，沒有依 FaceNet 分數搜尋此輪 DI 設定。

03 / TRANSLATION-INVARIANT GRADIENT

TI — Translation-Invariant
平移不變梯度

反向傳播後，先整合鄰近位置的梯度，再決定更新方向。

DI 處理模型的輸入，TI 處理 loss 回傳的梯度。做法是用正規化 Gaussian kernel，對原圖空間的梯度做加權平均，讓像素的更新方向也參考鄰近位置的資訊。

5×5 Gaussian、σ＝1
權重總和＝1

gTI = K ∗ gg：原始梯度；K：Gaussian kernel

在這個5×5範圍內，中央權重較高，越遠的鄰居權重越低。RGB 各通道獨立處理，邊界採 replicate padding。

TI 用梯度卷積近似平移集合的最佳化；有限 kernel 與邊界處理下，不保證任意平移都完全不變。

接到 MI-FGSM＋DI 的位置

DI backward取得原圖梯度
→
TI convolutionGaussian 加權平均
→
L1＋momentum正規化並累積方向
→
Sign＋projection更新δ，維持ε限制

TI 放在 sign 之前，才能先利用梯度大小和方向做平均。MI 的 momentum 再跨步累積方向。最後以降低 A–B_adv cosine 的方向更新，並把 δ 投影回 ε 範圍。

加入 TI 後：14/20 → 16/20，70% → 80%。
新增 Michelle Collins、Jorge Rodolfo Canicoba Corral 成功，沒有成功轉失敗；四個階段的 ArcFace 白箱結果均為20/20。
