# Historical Archive — Not for Formal Analysis

本目錄及 `results/archive/` 保存有歷史價值、但已退出目前 LFW 研究主線的材料。
**它們不得作為正式分析依據，不得引用為 baseline、門檻、attack 成功率或
perceptual 結論。**

正式研究只以 `docs/RESEARCH_STATUS.md` 及其 authority table 為準；正式 protocol
見 `docs/EXPERIMENT_PROTOCOL.md`。

## Structure

- `docs/`：舊架構審查、migration、歷史操作指令與過時 compare 說明。
- `legacy_results_notes/`：sun / musk 與舊 single-image pipeline 的文字註記。
- `results/archive/`：實際歷史輸出，依 `smoke/`、`historical_single_image/`、
  `historical_meeting/` 分類。該目錄的導覽與限制見 `results/archive/README.md`。

保留 archive 是為了 provenance 與可追溯性，並不表示其數字仍可比較或可升格為
正式結果。新的正式實驗不得沿用 archive 中的 legacy threshold、pair semantics
或報表解讀。
