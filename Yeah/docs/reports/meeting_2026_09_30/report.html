Experimental Setup & Cosine Threshold

Face verification 以 embedding 的 cosine similarity 判斷 pair 是否為同一人。untargeted dodging attack 的成功條件，是把原本通過 threshold 的 clean pair 推到 threshold 下方。

high similarity · same identitythresholdlow similarity · different identity
clean cosine ≥ threshold→adversarial cosine < thresholdattack success
Illustrative example · FaceNet（概念示意，非正式 sample）
clean cosine = 0.72，0.72 ≥ 0.4048 → same identity
adversarial cosine = 0.38，0.38 < 0.4048 → different identity → attack success
ThresholdsArcFace = 0.140721
FaceNet = 0.404789
EvaluationASR = successful identities / 20
cosine drop = clean cosine − adversarial cosine

Fixed setup: n = 20, ε = 0.04, 200 steps, ArcFace → FaceNet, untargeted verification dodging.

Equal L∞ ≠ Equal Perceptual Distortion
所有方法的 actual L∞ 都是 11/255，但 Mask 方法的 changed-pixel ratio 約由 30% 降至 12.1%，總擾動量也較低；這些方法間差異與 SSIM / LPIPS / DISTS 的改善一致。因此，只使用 L∞ 無法完整描述影像的 perceptual distortion。

Metric / Statistical / Provenance Appendix

Metric details

cosine similarity 越高代表 embedding 越相似；ASR 為 adversarial cosine 在 threshold 下方且 clean pair 有效的比例。actual L∞ 為 decoded PNG 最大 pixel 改動。SSIM 越高越接近原圖；LPIPS、DISTS 越低越接近原圖。

Statistical details

Paired comparisons、correlation、Wilcoxon、McNemar 與 crossing 的完整統計結果收錄於既有分析資料。

Provenance
